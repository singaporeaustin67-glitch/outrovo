FAQ

Questions, answered

Where does Outrovo get its data?

Every result comes from live public sources queried at search time — Wikidata, Wikipedia, GitHub, Bluesky, OpenAlex, Hacker News, DEV.to, Mastodon, Product Hunt, YouTube, Hugging Face, npm, arXiv, PubMed, DBLP, Crossref, ORCID, MusicBrainz, Mixcloud, Dailymotion, Open Library, Codeberg, Lobsters, and 180+ Stack Exchange expert communities. There is no seed database and no static lists: if a profile appears, it was fetched and reviewed in real time.

How does the fit score work?

An AI reviewer reads each candidate's real profile data and scores fit from 0–100 against your request, with a written explanation and evidence highlights. Scores are deliberately strict — only strong, specific matches score above 80.

What kinds of people can I find?

Influencers and creators with verified social handles, developers and open-source contributors, founders, investors, researchers, and other public figures. The agent picks the right sources for each request automatically.

Can I change the AI model behind Outrovo?

Yes. Outrovo talks to any OpenAI-compatible endpoint — the provider, key, and model are simple environment settings, with automatic failover to backup models if one hits its limits.
